# 🚀 Personal Portfolio Website

A modern, responsive, and minimalist personal portfolio website designed to showcase my software development projects, technical skills, and background. Built with a clean dark theme, purple accent palette, and subtle glassmorphism design elements.

---

## 🛠️ Tech Stack

* **HTML5**
* **CSS3**
* **JavaScript (ES6+)**
* **FontAwesome**
* **Git & GitHub**

---

## 📂 Site Structure

The portfolio is split into dedicated, lightweight subpages for seamless navigation:

* `index.html`
* `about.html`
* `projects.html`
* `contact.html`

---

## ✨ Features

- **Responsive Design:** Optimized for smooth reading across mobile devices, tablets, and desktops.
- **Dynamic Typewriter Effect:** Custom vanilla JavaScript hero headline animation.
- **Interactive Project Cards:** Hover mechanics highlighting repository links and technology stacks.
